# TradeTalk · 外贸英语口袋卡

React + Tailwind CSS + Vite 纯前端 MVP。无需后端或数据库。

已支持英语朗读（美音/英音）、PWA 安装与离线缓存。逐步使用及 Vercel 部署说明见 DEPLOYMENT.md。

最新版本增加场景目录、收藏复习、已学会标记和学习进度，并采用浅绿色界面。替换文件清单、验证与重新部署步骤见 UPGRADE.md。

## 运行

安装 Node.js 22.12 或更高版本，然后在本目录打开终端：

```sh
npm install
npm run dev
```

打开终端显示的 Local 地址，通常为 http://localhost:5173。

## 构建

```sh
npm run build
npm run preview
```

构建产物在 dist/；部署到静态网站托管即可。不要直接双击 index.html。

## 使用

- 学习页：点击卡片展开翻译与例句；“换一张”随机切换且不会连续重复。
- 管理页：填写全部四个字段并保存，新话术立即加入词库。
- 预置 184 条话术：原有 72 条 + 112 条服装 B2B 专用话术；服装内容优先展示。
- 内置数据位于 src/data.js，字段为 english、chinese、scene、example，另有唯一 id。
- src/storage.js 导入数据并按 id 与旧版 LocalStorage 合并；不用清空缓存，自定义话术仍保留。
- 内置话术的场景标签统一为新版分类；已存的英文、中文、例句保持原样。
- 每次加载都会补齐缺少的内置话术；新增时整个合并词库写入 LocalStorage。
- 保存失败会保留表单；读取失败会展示示例并暂停保存，避免覆盖异常数据。
- 数据仅保存在当前浏览器、当前站点；清除网站数据会删除词库。换浏览器或更换端口不会自动同步。

项目包含 package-lock.json，后续可用 npm ci 按锁定版本安装。

## 从旧版升级

把新版 src/data.js 和 src/storage.js 复制到旧项目的 src/ 目录，替换同名文件。
App.jsx 无需修改。开发模式下刷新页面即可；如果正在预览 dist/，先重新执行 npm run build。

## 服装行业升级

新增 7 个服装场景，每类 16 条：MOQ 与起订量、打样费用与时间、面料与辅料确认、尺寸表与版型修改、大货进度与尾期检验、付款方式与催尾款、包装要求与发货物流。

服装话术的实战例句为 Buyer / Supplier 双方对话。原有 72 条与用户自行添加的内容继续保留，storage.js 无需修改。App.jsx 的例句增加 whitespace-pre-line 样式，按行展示买卖双方对话，原有功能保持不变。

开发模式运行 npm run dev 后刷新；生产预览模式先运行 npm run build，再运行 npm run preview 并刷新。继续使用同一个网址和端口可以保留现有浏览器词库。
