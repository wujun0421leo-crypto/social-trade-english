## 第二步：本地查看

```powershell
npm.cmd install
npm.cmd run dev
```

如果旧开发服务仍在运行，先在对应终端 Ctrl+C，再重新启动。
打开终端提供的网址。主导航现在包含“学习、目录、收藏、管理”。

## 第三步：使用新功能

1. 在“目录”中选择一个场景，或在学习页的场景下拉框切换。
2. “换一张”只从当前场景抽取，并避免连续重复；只有一句时禁用换卡按钮。
3. 点击星星收藏话术；在“收藏”中查看、取消收藏，或开始收藏复习。
4. 收藏复习只抽取收藏内容，移除最后一条后展示空状态。
5. 点击“标记已学会”记录进度，再次点击可以撤销。展开翻译不自动计为学会。
6. 总进度按全部词库统计，分类进度按当前场景统计，收藏页另有收藏复习进度。
7. 管理页新增的话术会立即计入对应目录；新增场景会自动成为目录的一项。

词库继续使用 tradetalk.cards.v1；收藏和进度保存在独立的 tradetalk.learning.v1 中。
浏览器存储写入失败时，不会把失败操作显示成已收藏或已学会。
记录按卡片稳定 id 保存，统计只计算当前词库实际存在的卡片。
记录仍属于当前设备、浏览器和站点；相同部署域名下更新不会主动清除旧数据。
